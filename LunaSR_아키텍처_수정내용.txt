LunaSR 아키텍처 수정 내용 (최고 퀄리티 / 퀄리티 / 밸런스)
작성일: 2026-02-20

1) 목적
- LunaSR 모드를 3단계로 명확히 분리:
  - 밸런스(balanced)
  - 퀄리티(quality)
  - 최고 퀄리티(ultra_quality)
- 특히 퀄리티 계열에서 "실제 화질 개선"이 체감되도록 파이프라인을 확장.

2) 핵심 아키텍처 변경점

[A] 단일 보정 -> 다단 보정 구조로 변경
- 기존: 1회 bilateral 기반 보정 + 보간 + 샤픈/클램프.
- 변경: 다단 아티팩트 보정(run_artifact_fix) 추가.
  - artifact_passes 단계 수를 모드별로 다르게 적용.
  - 각 패스마다 sigma/강도를 조절해 블록/링잉 억제 누적.

[B] 엣지 가이드 디테일 복원 모듈 추가
- 업스케일 후 단순 샤픈이 아니라:
  - edge_gate(엣지/텍스트 마스크 기반)
  - source_detail_gain(원본 고주파 복원)
  - refine_gain(보간 결과 디테일 재주입)
- 결과: 텍스트/라인아트 주변의 선명도 유지와 과샤픈 억제를 동시에 달성.

[C] 품질 모드의 리샘플링/크로마 정책 강화
- 밸런스: 빠른 CUBIC + LINEAR 크로마.
- 퀄리티: LANCZOS4 + CUBIC 크로마.
- 최고 퀄리티: LANCZOS4 + LANCZOS4 크로마.
- 품질 모드에서 색 번짐/엣지 흐림을 줄이도록 설계.

[D] 디더링을 단일층 -> 다층으로 확장
- 기존: 1층 노이즈 디더.
- 변경: dither_layers(1~3)로 다층 디더 적용.
  - 밴딩 구간에서 더 자연스러운 계조 전이.
  - 모드가 높을수록 다층 적용.

[E] 프리블러(preblur_sigma) 기반 샘플 안정화
- 품질 모드에서 보간 직전 미세 preblur를 추가해 alias/깜빡임 리스크를 완화.
- 최고 퀄리티에서 강도를 더 높여 안정성 우선.

3) 모드별 동작 차이

- balanced (속도 우선)
  - artifact_passes=1
  - refine_gain/source_detail_gain 낮음
  - preblur 없음
  - CUBIC + LINEAR
  - dither_layers=1

- quality (품질/속도 균형, 기존 quality 대비 화질 강화)
  - artifact_passes=2
  - edge-guided detail 복원 활성 강화
  - preblur 적용
  - LANCZOS4 + CUBIC
  - dither_layers=2

- ultra_quality (최고 화질)
  - artifact_passes=3
  - detail 복원 강도 최대
  - preblur 강도 증가
  - LANCZOS4 + LANCZOS4
  - dither_layers=3

4) 자동 튜닝(auto_tune) 확장
- 기존 블록/노이즈/텍스트 비율 기반 튜닝에 더해:
  - refine_gain, source_detail_gain, artifact_passes를 동적 조정.
- 콘텐츠 특성(압축 흔적/텍스트 밀도)에 따른 모드 내 세부 보정이 가능.

5) 수정 파일
- scripts/lunasr_universal.py
  - 3티어 모드 체계 도입
  - 다단 아티팩트 보정, 엣지 가이드 디테일 복원, 다층 디더 추가
  - 품질 티어 파서 추가 (balanced/quality/ultra_quality + 한글 별칭)
- scripts/lunasr_fg_video.py
  - LunaSR 모드 선택을 quality-tier 기반으로 변경
  - 기존 quality-mode(0/1/2)는 레거시 호환 유지

6) 사용 예시

- 이미지 x2 (퀄리티)
python scripts\lunasr_universal.py --input "test mp4 and jpg\KakaoTalk_20250721_183628948_08.png" --output "test mp4 and jpg\results\png_lunasr_quality_x2.png" --scale 2.0 --quality-tier quality --auto-tune

- 이미지 x2 (최고 퀄리티)
python scripts\lunasr_universal.py --input "test mp4 and jpg\KakaoTalk_20250721_183628948_08.png" --output "test mp4 and jpg\results\png_lunasr_ultra_x2.png" --scale 2.0 --quality-tier ultra_quality --auto-tune

- FG + LunaSR 비디오 (퀄리티)
python scripts\lunasr_fg_video.py --input "test mp4 and jpg\KakaoTalk_20250725_105553305.mp4" --output "test mp4 and jpg\results\video_lunasr_fg_quality_x2.mp4" --scale 2.0 --quality-tier quality --auto-tune --fg-model model\model.onnx --fg-size 256 --fg-precision f16

7) 비고
- quality-tier를 명시하지 않으면 기본은 quality.
- quality-mode는 기존 스크립트 호환을 위해 남겨두었고, 신규 사용은 quality-tier 권장.

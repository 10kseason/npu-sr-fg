좋아. 그럼 “범용(캡처 기반) + 인텔 iGPU 친화 + 실시간”이라는 제약을 **정면으로 먹고도 이득이 나는** 알고리즘 스펙을 **v0.1로 딱** 짜줄게.
(난 이걸 “FSR2/DLSS 흉내”가 아니라, **유튜브/디코/OBS/창 전체에서 체감이 크게 나는** 방향으로 설계할 거야.)

# LunaSR-Universal v0.1 (Intel iGPU-friendly)

**목표:** 캡처 기반(시간/모션벡터/뎁스 없음)에서도

1. **압축 찌꺼기(블록/링잉/밴딩)**를 줄이고
2. **UI/텍스트/라인아트**를 망치지 않으면서
3. **업스케일(최대 2× 권장)**을 “깔끔하게” 만든다.
   **핵심:** “Upscale만” 하지 말고 **Artifact-aware Resampling**으로 간다.

---

## 전체 파이프라인 (단일 Compute Pass 설계)

**입력:** NV12 (Y + UV) 또는 RGBA(가능하면 YUV 추천)
**출력:** RGBA(또는 NV12)
**실행:** 1 pass에서 “전처리 + 업스케일 + 후처리”를 합쳐서 메모리 왕복 최소화

### 핵심 구성 3요소

1. **Artifact-aware Luma Fix (국소, 약하게)**

   * 블록 경계/밴딩 후보를 찾고 “필요한 곳만” 누른다 (전체 블러 금지)
2. **Edge-aware Resampling (방향성 + bilateral 가중)**

   * 엣지 방향을 추정해서 **엣지를 가로질러 섞지 않게** 보간
3. **Anti-ringing Sharpen + Clamp + Deband Dither**

   * 선명도는 올리되, 링잉/헤일로는 원천 봉쇄
   * 밴딩은 “미세 디더”로 숨김(필요한 곳만)

---

# 1) 핵심 아이디어: “Joint Bilateral Resampling”

캡처 기반에서 가장 큰 문제는:

* 업스케일하면 **블록/링잉/밴딩이 같이 커진다**
* 엣지(텍스트/라인) 주변에서 **크로스 블렌딩**이 일어나면 바로 티난다

그래서 보간을 이렇게 바꾼다:

## 1-A. 기본 보간 커널

기본은 빠른 **Lanczos2** 또는 **Catmull-Rom(bicubic)** 중 선택.

* 성능 우선이면 Catmull-Rom(4×4 taps = 16 taps)
* 품질 우선이면 Lanczos2(역시 4×4 = 16 taps)

여기까진 “기존”이야.
**새로움은 여기부터:**

## 1-B. Sample 가중에 Bilateral을 곁들임

각 샘플 (s_i)에 대해, 기본 커널 가중 (k_i)에다가
**(1) 값 차이(색/밝기)** + **(2) 엣지 법선 방향 거리**를 이용한 추가 가중 (b_i)를 곱한다.

[
w_i = k_i \cdot b_i
]

[
b_i = \exp_2(-\alpha \cdot (s_i - s_c)^2); \cdot; \exp_2(-\beta \cdot d_{\perp}^2)
]

* (s_c): 중심 샘플(혹은 가장 가까운 샘플)
* (d_{\perp}): 엣지 **법선 방향**으로의 거리 성분 (엣지를 가로지르는 샘플일수록 패널티)
* (\alpha,\beta): 튜닝 파라미터 (값 차이 민감도 / 공간 민감도)

**이거 하나로 효과가 큼:**

* 텍스트/라인 주변에서 **엣지 넘어 섞이는 현상 급감**
* 압축 링잉이 과하게 “번지는” 현상 감소

---

# 2) 엣지 방향(orientation) 추정: “구조 텐서 간이판”

시간 정보가 없으니, 프레임 단독으로 엣지를 뽑아야 함.

출력 픽셀이 참조하는 입력 좌표 (p) 주변(3×3)에서 Sobel로 기울기:

[
g = (g_x, g_y)
]
[
g_x = \text{SobelX}(Y),\quad g_y = \text{SobelY}(Y)
]

엣지 법선 (n)과 접선 (t):
[
n = \frac{g}{|g|+\epsilon}, \quad t = (-n_y, n_x)
]

그리고 “엣지 확실함(비등방성)” (a)를 하나 만든다:
[
m = |g|
]
[
a = \text{saturate}\Big(\frac{m - m_0}{m_1 - m_0}\Big)
]

* (m_0): 약한 엣지 기준(텍스트가 걸리는 정도)
* (m_1): 강한 엣지 기준(진짜 선/경계)

이 (a)가 크면 클수록, 위의 bilateral에서 (\beta)를 키워서
**엣지를 가로지르는 샘플을 더 강하게 억제**하면 됨.

---

# 3) “블록 아티팩트”를 업스케일 과정에 녹이기

여기서부터가 “범용에 진짜 체감”이 나.

## 3-A. 블록 후보 위치

JPEG/스트리밍은 보통 8×8/16×16 경계에서 문제가 생김.
입력 좌표에서:

* (u = p_x), (v = p_y)
* 경계 근접도:
  [
  b_x = 1 - \text{saturate}\Big(\frac{|\text{frac}(u/8)-0.5|}{0.5}\Big)
  ]
  (8px 경계 근처면 1에 가까움)
  y도 동일해서 (b_y), 그리고 (b = \max(b_x, b_y))

## 3-B. “진짜 엣지” vs “블록 찌꺼기” 구분

핵심은 이거야:

* 블록은 경계에 “갑자기” 생기는데, 구조 텐서 관점에서 **일관된 방향성**이 약한 경우가 많음
* 반대로 진짜 엣지는 방향성이 강함((a) 큼)

그래서 블록 스무딩을 이렇게 제어:
[
\gamma_{\text{block}} = b \cdot (1-a)
]

즉, **경계 근처(b 큼) + 엣지 확실하지 않음(1-a 큼)** → 블록일 확률이 높다.

이 (\gamma_{\text{block}})로 bilateral의 (\alpha) 또는 (\beta)를 살짝 조정해서
경계만 “살짝” 붙인다(과하면 뭉개짐).

---

# 4) 밴딩 제거: “필요한 곳만 미세 디더”

밴딩은 “필터로 지우면” 오히려 뭉개지고 더 티남.
정답은 **미세 디더**야(근데 아무 데나 뿌리면 노이즈 지옥).

## 4-A. 밴딩 후보 마스크

밴딩은 보통:

* 기울기 (m)가 작고(거의 평면)
* 라플라시안(2차 미분)도 작고(엣지 없음)
* 그런데 계조가 계단처럼 보임(양자화)

실용적으로는 이렇게 충분히 잡힘:
[
band = (1-a)\cdot \text{saturate}\Big(\frac{m_{low}-m}{m_{low}}\Big)
]
(엣지 아닌 평탄 영역만)

## 4-B. 디더 주입

블루노이즈 텍스처 하나(64×64) 가져와서:
[
Y \leftarrow Y + (noise-0.5)\cdot ditherAmp \cdot band
]

* ditherAmp는 보통 0.3/255 ~ 1.0/255 사이
* band가 0이면 주입 0

---

# 5) 샤픈: “선명하게, 대신 링잉은 봉쇄”

범용 업스케일에서 샤픈은 필수인데, 헤일로/링잉 생기면 바로 망함.

## 5-A. 로컬 평균을 같은 샘플 세트로 만든다

업스케일 결과 (y_0)을 얻을 때 사용한 샘플 (s_i)들로
“부드러운 평균” (y_{mean})도 같이 계산:

[
y_{mean} = \frac{\sum k_i \cdot s_i}{\sum k_i}
]

그리고 unsharp:
[
y = y_0 + sharp \cdot (y_0 - y_{mean})
]

## 5-B. Anti-ringing clamp (핵심)

샘플 세트에서 min/max를 뽑고, 샤픈 결과를 제한:

[
y \leftarrow \text{clamp}(y, minS - \delta, maxS + \delta)
]

* (\delta)는 0~(1/255) 정도의 여유
* 텍스트 마스크에서는 (\delta) 더 작게(보수적으로)

이 클램프 하나가 “선명한데 지저분하지 않게”를 만들어줘.

---

# 6) 텍스트/UI 보호 마스크

텍스트는 “가늘고 강한 엣지”가 핵심이라,
필터/디노이즈가 조금만 과해도 즉시 망가짐.

## 6-A. 간단 텍스트 마스크

입력 주변 로컬 대비 + 엣지 강도:
[
text = \text{saturate}\Big(\frac{m - t0}{t1 - t0}\Big)\cdot \text{saturate}\Big(\frac{var - v0}{v1 - v0}\Big)
]

* var은 3×3 분산(대충 2차 모멘트)
* 텍스트는 보통 분산이 높고, 엣지도 강함

## 6-B. 텍스트 영역에서 정책

* bilateral 강도 낮추기(뭉개짐 방지): (\alpha)↑, (\beta)↑ 또는 반대로 섞임 억제 강화
* deblock/deband 약화
* sharpen은 “클램프 강하게” + sharp 낮추기

# 구현 스펙 (HLSL Compute Shader 형태)

## 스레드/타일

* 권장: **8×8** 또는 **16×16** threads / group
* 샘플 반경 2(4 taps)면, 그룹마다 입력 타일을 **groupshared**로 캐싱하면 iGPU에서 이득 큼
  (근데 처음 v0.1은 캐싱 없이도 시작 가능. 성능 모자라면 캐싱 넣자.)

## 품질 모드(현실적인 타협)

* **Q0 (Fast)**: Catmull-Rom 4×4(16 taps), 간이 bilateral(값 차이만), clamp만
* **Q1 (Balanced)**: Catmull-Rom + 값차이 + 법선거리 bilateral + 텍스트마스크
* **Q2 (Quality)**: Lanczos2 + 풀 bilateral + deblock/band dither + sharpen

나는 윾이면 **Q1부터** 갈 거야. Q2는 iGPU에서 4K가 빡셀 수 있음.

---

## HLSL 유사 의사코드 (핵심만)

```hlsl
// Constants (tunable)
cbuffer Params {
  float2 inSize, outSize;
  float2 scale;              // in->out mapping: in = out / scale
  float  m0, m1;             // edge thresholds
  float  alphaBase, betaBase;
  float  blockStrength;      // 0..1
  float  sharpBase;          // 0..1
  float  clampDelta;         // ~0..1/255
  float  ditherAmp;          // ~0.3/255..1/255
  float  textT0, textT1, varV0, varV1;
  int    qualityMode;        // 0..2
};

// Read luma from NV12 or computed from RGB
float Yat(int2 ip);
float2 UVat(int2 ip); // for NV12

// Sobel gradient around p (input space)
void SobelGrad(float2 p, out float gx, out float gy, out float varLocal) {
  // sample 3x3 nearest ints; compute sobel + variance (cheap)
}

float Lanczos2(float x);      // or CatmullRom
float Kernel(float x, int mode);

// Blue noise
float BlueNoise(int2 op);     // [0..1]

[numthreads(8,8,1)]
void CS(uint3 dtid : SV_DispatchThreadID) {
  int2 op = int2(dtid.xy);
  if(op.x >= outSize.x || op.y >= outSize.y) return;

  // map output -> input continuous coord
  float2 p = (float2(op) + 0.5) / scale - 0.5;

  // edge info
  float gx, gy, varLocal;
  SobelGrad(p, gx, gy, varLocal);
  float m = sqrt(gx*gx + gy*gy) + 1e-6;
  float2 n = float2(gx, gy) / m;        // normal
  float  a = saturate((m - m0) / (m1 - m0)); // anisotropy

  // text mask
  float text = saturate((m - textT0)/(textT1-textT0)) * saturate((varLocal - varV0)/(varV1-varV0));

  // block proximity mask (8x8)
  float bx = 1 - saturate(abs(frac(p.x/8.0) - 0.5)/0.5);
  float by = 1 - saturate(abs(frac(p.y/8.0) - 0.5)/0.5);
  float b  = max(bx, by);
  float gammaBlock = b * (1 - a) * blockStrength * (1 - text);

  // bilateral params (text-protect)
  float alpha = alphaBase * lerp(1.0, 1.5, text);
  float beta  = betaBase  * lerp(1.0, 2.0, a) * lerp(1.0, 1.5, text);

  // resample neighborhood 4x4 around floor(p)
  int2 ip0 = int2(floor(p));
  float2 f = p - float2(ip0);

  float sumW = 0, sumWY = 0;
  float sumK = 0, sumKY = 0;   // for mean (no bilateral)
  float minS =  1e9, maxS = -1e9;

  // center sample
  float sc = Yat(ip0);

  [unroll] for(int j=-1;j<=2;j++){
    float kj = Kernel(f.y - j, qualityMode);
    [unroll] for(int i=-1;i<=2;i++){
      float ki = Kernel(f.x - i, qualityMode);
      float k  = ki * kj;
      int2 ip  = ip0 + int2(i,j);
      float s  = Yat(ip);

      // distance across edge normal (approx)
      float2 d = float2(i - f.x, j - f.y);
      float dperp = dot(d, n);

      // bilateral (fast exp2)
      float dv = (s - sc);
      float bw = exp2(-alpha * dv*dv) * exp2(-beta * dperp*dperp);

      // deblock assist: if likely block artifact, reduce penalty across boundary (slight smoothing)
      bw = lerp(bw, 1.0, gammaBlock * saturate(1 - abs(dperp))); // gentle

      float w = k * bw;
      sumW  += w;
      sumWY += w * s;

      sumK  += k;
      sumKY += k * s;

      minS = min(minS, s);
      maxS = max(maxS, s);
    }
  }

  float y0 = sumWY / max(sumW, 1e-6);
  float yMean = sumKY / max(sumK, 1e-6);

  // sharpen + clamp
  float sharp = sharpBase * (1 - 0.7*text); // protect text
  float y = y0 + sharp * (y0 - yMean);
  y = clamp(y, minS - clampDelta, maxS + clampDelta);

  // banding dither (flat non-edge)
  float band = (1 - a) * saturate((m0 - m) / m0) * (1 - text);
  float noise = BlueNoise(op) - 0.5;
  y += noise * ditherAmp * band;

  // chroma upscale (simple bilinear is fine)
  float2 uv = /* bilinear UVat around p/2 for NV12 */;
  float3 rgb = YUV2RGB(y, uv);

  // output
  StoreRGBA(op, float4(rgb, 1));
}
```

# 튜닝 파라미터 테이블 (v0.1 기본값 “추천 시작점”)

(정확한 수치는 영상/스케일에 따라 달라서, **일단 굴러가는 기본**을 잡아줄게)

* `m0`: 0.02 ~ 0.05 (엣지 약함 기준, 정규화된 Y일 때)
* `m1`: 0.10 ~ 0.18 (엣지 강함 기준)
* `alphaBase`: 20 ~ 80 (값 차이 민감도; 크면 더 “엣지 넘어 섞임” 억제)
* `betaBase`: 1.0 ~ 6.0 (법선 방향 억제; 크면 더 “엣지 가로 블렌딩” 억제)
* `blockStrength`: 0.1 ~ 0.35 (너무 크면 블록 대신 디테일도 붙음)
* `sharpBase`: 0.08 ~ 0.25 (클램프가 있으니 생각보다 올려도 됨)
* `clampDelta`: 0 ~ 1/255 (텍스트 많으면 작게)
* `ditherAmp`: 0.3/255 ~ 0.8/255

내 경험상(그리고 네 취향상)
**“선명한데 더러운 거 싫다”**면 `clampDelta`를 공격적으로 줄이는 게 맞아.

---

# 인텔 iGPU(루나레이크)에서 안 터지게 하는 운영 규칙

이건 진짜 중요해서 단호하게 말할게.

1. **2× 초과 업스케일은 v0.1에서 금지**

   * 1080→4K는 2× + 2×로 나눠도 되는데, 두 번 돌리면 지연/아티팩트가 늘어
   * v0.1은 1080→1440 / 1080→1800 / 720→1080 같은 데서 “완성”을 목표로 해
2. **Y만 진짜로 처리하고 UV는 단순 보간**

   * 체감 품질은 거의 Y에서 결정됨
   * UV까지 복잡하게 하면 iGPU 대역폭이 먼저 죽어
3. **품질은 Q1부터**

   * Q2(Lanczos2 + 풀 옵션)는 4K에서 버티기 힘들 수 있어
4. exp는 `exp2()`로 통일 + half 활용

   * 인텔 iGPU는 이런 곳에서 차이가 많이 남

# 이 알고리즘이 “새롭다/쓸모 있다”는 포인트 (내가 보는 승부처)

* 업스케일러 대부분은 “보간 + 샤픈”까지만 함
  → 그래서 **압축 찌꺼기를 확대**해버리는 경우가 잦음
* LunaSR-Universal은 **Resampling 그 자체가 Artifact-aware**라서

  * 유튜브 저비트레이트
  * 디코 화면공유
  * OBS 캡처
  * 웹영상
    이런 “진짜 범용 환경”에서 **깔끔함 체감**이 난다

* **(B) DX11/12 샘플 앱 구조**: Desktop Duplication → Compute → Swapchain 렌더까지 “뼈대” 설계

나는 개인적으로 **A부터 넣으면 ‘범용’이 확 살아난다**고 봐.
(범용 업스케일러는 “컨텐츠마다 최적값이 달라서” 자동 조절이 없으면 결국 수동노가다 됨)

원하면 내가 다음 메시지에서 **A(오토 튜너) 스펙**을 “규칙 + 수식 + 예외처리”까지 같이 박아줄게.
